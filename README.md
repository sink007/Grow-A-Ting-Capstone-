# Grow-A-Ting-Capstone-

#### **Yaad Garden (Grow-A-Ting)** is a free mobile app empowering low-income Jamaican households to grow healthy food in limited spaces, offering structured plant care, a visual growth diary, and AI-powered plant health diagnosis.

## Try Yaad Garden
#### Experience intelligent plant care with our comprehensive mobile application

## Getting Started

1. Download the APK file to your Android device

2. Enable installation from unknown sources in settings

3. Install and launch the Yaad Garden app

4. Create your account and start growing
